## Описание обрабатываемых данных
| Категория данных | Пример полей | Источник | Предполагаемое хранение | Ограничение доступа |
|---|---|---|---|---|
| Медиафайлы | Фото продукта (JPEG/PNG) | Камера/Галерея | ОЗУ, временный кэш | Для обслуживающих компонентов |
| Кулинарные данные | Название, ингредиенты, шаги | Backend API | ОЗУ, временный кэш | По валидному запросу |
| Учетные данные | Email, пароль, JWT-токен | Пользователь / Backend | Защищенное хранилище ОС (Keychain/Keystore) | Для обслуживающих компонентов |
| Настройки | Тема, язык, уведомления | Пользователь | LocalStorage / SharedPreferences | Для обслуживающих компонентов |
