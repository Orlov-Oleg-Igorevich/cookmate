# Матрица доступа
| Операция | Гость (Неаутентифицированный) | Авторизованный пользователь | Администратор / Разработчик |
|---|---|---|---|
| O-01. Загрузка фото и распознавание продуктов | Разрешено | Разрешено (синхронизация истории) | Не применимо (не использует UI) |
| O-02. Редактирование списка ингредиентов | Разрешено (в рамках текущей сессии) | Разрешено (сохранение предпочтений) | Не применимо |
| O-03. Просмотр списка рецептов | Разрешено (только из текущего поиска) | Разрешено (поиск + история + избранное) | Не применимо |
| O-04. Управление избранным (Add/Remove) | Запрещено | Разрешено (только собственные записи) | Разрешено (в случае непосредственного взаимодействия с бд при изменении списка рецептов, например, при отзыве рецептов от создателя) |
| O-05. Просмотр истории запросов | Запрещено | Разрешено (серверная история) | Разрешено (просмотр логов системы) |
| O-06. Аутентификация / Смена токена | Разрешено (вход/регистрация) | Разрешено (обновление сессии/выход) | Разрешено (сброс сессий пользователей) |
| O-07. Доступ к настройкам приложения | Разрешено | Разрешено | Не применимо |
